## 2. 設計原則

1. 手機優先。
2. 畫面舒適，留白足夠。
3. 每個頁面只承擔一個主要任務。
4. 文案精簡，盡量用短句、數字與卡片呈現。
5. 女性預設主題偏柔和、放鬆與輕盈；男性主題偏直接、俐落與指標導向。
6. 主題切換不改資訊架構，只改視覺語言。

## 5. 各頁面目的與內容層級

### 5.1 Landing Page

目的：讓訪客快速理解產品價值並進入登入流程。

主要內容：

1. 產品一句話價值主張
2. 拍照分析的主視覺
3. 三個核心優點
4. 非醫療用途簡短提醒
5. LINE Login CTA

### 5.2 Consent Intro

目的：在使用敏感資料前完成必要告知。

主要內容：

1. 收集哪些資料
2. 照片只暫存分析後刪除
3. 本服務非醫療用途
4. 同意按鈕

### 5.3 Home Dashboard

目的：作為會員登入後的主控台，快速進入最常用任務。

主要內容排序：

1. 拍照分析主按鈕
2. 最近一次分析摘要
3. 今日建議摘要
4. 熱門運動卡片
5. 個人目標小卡

### 5.4 Start Analysis

目的：讓使用者拍照或選擇照片。

主要內容：

1. 相機拍照入口
2. 相簿上傳入口
3. 圖片格式與大小提醒
4. 隱私提醒短句

### 5.5 Candidate Confirmation

目的：讓使用者確認 AI 辨識結果與份量。

主要內容：

1. 候選食物列表
2. 每個候選的信心分數
3. 修改食物名稱入口
4. 份量或重量輸入
5. 重新分析或繼續按鈕

### 5.6 Analysis Result

目的：以最短路徑提供營養結果與建議。

主要內容排序：

1. 總熱量與三大營養素摘要
2. 食物明細卡片
3. 每日目標建議
4. 推薦運動與預估熱量消耗
5. 歷史保存狀態與免責聲明

### 5.7 History List

目的：讓使用者快速回顧過往分析。

主要內容：

1. 日期
2. 食物摘要
3. 總熱量
4. 當次建議摘要
5. 點擊進入詳情

### 5.8 History Detail

目的：讓使用者比對單次分析的內容與建議。

主要內容：

1. 單次分析摘要
2. 食物明細
3. 三大營養素
4. 當次推薦建議快照
5. 免責聲明

### 5.9 Profile Edit

目的：維護個人身體資料與目標設定。

主要內容：

1. 年齡
2. 身高
3. 體重
4. 活動量
5. 目標類型
6. 目標體重或方向
7. 儲存按鈕

### 5.10 Theme Preference

目的：切換女性預設主題與男性主題。

主要內容：

1. 主題預覽卡
2. 主題切換說明
3. 儲存按鈕

## 6. 核心流程規格

### 6.1 Flow A 首次註冊與建檔

1. 訪客進入 Landing Page。
2. 點擊 LINE Login。
3. 完成授權。
4. 進入 Consent Intro。
5. 同意隱私與非醫療聲明。
6. 填寫 Profile Edit 基本資料。
7. 進入 Home Dashboard。

成功條件：

1. 使用者完成登入。
2. 同意紀錄已保存。
3. Profile 已建立。

### 6.2 Flow B 食物拍照分析

1. 使用者從 Home 點擊拍照分析。
2. 進入 Start Analysis。
3. 拍照或上傳圖片。
4. 系統分析中。
5. 進入 Candidate Confirmation。
6. 使用者確認食物與份量。
7. 進入 Analysis Result。
8. 系統保存分析摘要供歷史查看。

成功條件：

1. 顯示總熱量與三大營養素。
2. 顯示個人化建議與推薦運動。
3. 原始照片不長期保存。

### 6.3 Flow C 查看歷史紀錄

1. 使用者進入 History List。
2. 點擊某筆分析。
3. 進入 History Detail。

成功條件：

1. 可看到食物摘要、營養結果與建議快照。
2. 不顯示原始食物圖片。

### 6.4 Flow D 調整個人目標

1. 使用者從 Profile 進入編輯。
2. 更新體重、活動量或目標。
3. 儲存後返回 Home。
4. 後續新分析採用更新後的設定。

成功條件：

1. 變更資料保存成功。
2. 下次分析結果以新設定計算。

### 6.5 Flow E 切換主題

1. 使用者進入 Theme Preference。
2. 選擇女性預設或男性主題。
3. 儲存後立即套用。

成功條件：

1. 視覺主題更新成功。
2. 重新登入後仍保留設定。

## 7. 畫面內容策略

### 7.1 文案策略

1. 每個區塊先給結論，再給一行輔助說明。
2. 減少抽象術語與過長說明。
3. 建議文案採一般健康管理語氣，不做權威醫療語氣。

### 7.2 視覺策略

1. 女性主題使用柔和色、較大留白、較舒展的排版節奏。
2. 男性主題使用較高對比、較直接的資訊呈現與較俐落字重。
3. 卡片為主要資訊承載單元。
4. 重要數字優先大字呈現。

## 8. 表單與輸入規格

### 8.1 Profile 欄位

1. 年齡
2. 身高 cm
3. 體重 kg
4. 活動量
5. 目標類型
6. 目標體重或方向

### 8.2 分析修正欄位

1. 食物名稱
2. 份量數值
3. 份量單位或重量

## 9. 錯誤與空狀態

### 9.1 AI 辨識失敗

1. 顯示簡短說明
2. 提供重新上傳
3. 提供手動輸入食物入口

### 9.2 尚無歷史紀錄

1. 顯示空狀態插圖
2. 引導去做第一次拍照分析

### 9.3 個人資料未完成

1. 阻擋進入個人化建議結果
2. 引導完成基本資料

## 10. 驗證重點

1. 首次流程是否過長。
2. 拍照分析後是否能在短時間內得到足夠有用的結果。
3. 手動修正是否足夠直覺。
4. 歷史紀錄是否足夠支援回顧與比較。
5. 女性預設主題是否真的舒適，而不是過度裝飾。
6. 男性主題是否有差異，但不造成產品維護成本過高。
