# HappyMeal Consent 與聲明文案稿 v1

- 文件名稱：HappyMeal Consent 與聲明文案稿
- 版本：v1
- 日期：2026-04-21
- 狀態：Draft
- 用途：作為 Consent Intro 正式上線文案的基線，提供產品、設計與前端同步使用。

---

## 1. 文件定位

本文件不是新的產品需求文件，不取代 [PRD-v1.md](./PRD-v1.md)。

本文件的用途是定義 Consent Intro 與日常回看入口的正式上線文案，包含：

1. 頁面摘要文案
2. 可收合展開的正式段落文案
3. 兩個 checkbox 的勾選文字
4. 主按鈕文案
5. 全站頁尾回看連結文字
6. 結果與歷史詳情的短版非醫療提醒文案

---

## 2. 文件類型

- 類型：Reference 參考文件
- 目標讀者：產品、設計、前端與後續維護人員
- 使用者目標：確認 Consent Intro 正式上線時，頁面應顯示哪些文案與互動文字
- 範圍：處理 Consent Intro、日常頁尾回看入口與短版非醫療提醒；不處理法務後台、多版本管理介面或完整外部法律文件

## 3. 頁面摘要文案

### 3.1 頁面標題

開始分析前，請先完成兩項必要同意

### 3.2 頁面摘要

你可以先閱讀重點摘要，再依需要展開完整內容。完成隱私政策與非醫療用途聲明兩項勾選後，才能開始新的分析與建議流程。

## 4. 隱私政策文案

### 4.1 區塊標題

隱私政策說明

### 4.2 區塊摘要

我們會使用你的基本身體資料、目標設定與食物照片來完成分析，原始照片僅供本次分析暫存，完成後不長期保存。

### 4.3 展開後正文

為了提供飲食分析、營養估算與個人化建議，HappyMeal 會處理你填寫的年齡、身高、體重、活動量、目標設定，以及你上傳的食物照片與分析結果摘要。

原始食物照片僅用於本次分析流程的暫存處理，分析完成後不作長期保存。歷史紀錄中保存的是分析摘要、營養結果與建議快照，不包含原始照片。

你的資料僅用於提供本服務所需的功能與體驗優化，不會因前端流程需要而把第三方金鑰或敏感設定暴露在瀏覽器端。

### 4.4 Checkbox 文案

我已閱讀並同意目前版本的隱私政策

## 5. 非醫療用途聲明文案

### 5.1 區塊標題

非醫療用途聲明

### 5.2 區塊摘要

本服務提供的是一般健康管理與 wellness guidance 參考，不構成醫療診斷、治療、處方或專業醫療建議。

### 5.3 展開後正文

HappyMeal 提供的熱量、營養與運動建議，屬於一般健康管理與 wellness guidance 參考，目的在於協助你理解單次飲食與活動安排。

所有營養結果與建議都屬於估算資訊，不能取代醫師、營養師或其他合格醫療專業人員的判斷，也不應被解讀為診斷、治療、處方或疾病管理方案。

如果你有慢性病、特殊飲食限制、孕期需求或任何健康疑慮，請優先諮詢合格醫療專業人員，再決定是否依據本服務的資訊調整飲食或運動安排。

### 5.4 Checkbox 文案

我已閱讀並同意非醫療用途聲明

## 7. 顯示規則

1. 兩個文案區塊預設皆為收起狀態
2. 每個區塊需顯示標題與一行摘要
3. 使用者可自行展開閱讀完整內容
4. 只有兩個 checkbox 都勾選後，主按鈕才可啟用
5. 若尚未勾選完成，需提供清楚的輔助提示，不可只依賴 disabled 狀態
6. Consent Intro 是首次必要同意流程，不可被頁尾回看連結取代

## 8. 全站頁尾回看入口

### 8.1 顯示位置

完成必要同意後，會員狀態的主要頁面最下方應顯示輕量文字連結，讓使用者可隨時回看隱私與聲明內容。

適用頁面包含：

1. Home Dashboard
2. Start Analysis
3. Candidate Confirmation
4. Analysis Result
5. History List
6. History Detail
7. Profile Edit
8. Theme Preference

### 8.2 連結文字

建議顯示為：

```text
隱私政策
非醫療用途聲明
```

若需要單行呈現，可使用：

```text
隱私政策與非醫療用途聲明
```

### 8.3 顯示規則

1. 頁尾只顯示連結文字，不常駐完整政策或完整聲明段落。
2. 點擊後可導向同頁 review 區塊、獨立 review view，或後續正式 policy page。
3. 頁尾入口只作為日常回看，不代表使用者已完成首次必要同意。
4. 未完成必要同意時，仍應導向 Consent Intro 與兩個 checkbox 主鏈。

## 9. 短版非醫療提醒文案

### 9.1 適用位置

以下畫面因直接呈現營養結果、目標與運動建議，應保留短版非醫療提醒：

1. Analysis Result 的 recommendation 附近
2. History Detail 的建議快照附近

### 9.2 建議文案

```text
本建議僅供一般健康管理參考，不構成醫療診斷、治療或處方。
```

若空間更有限，可使用：

```text
一般健康管理參考，非醫療建議。
```

### 9.3 顯示規則

1. 短版提醒應靠近建議內容，而不是只放在頁尾。
2. 短版提醒不需要大型卡片，也不需要重複完整聲明段落。
3. 語氣保持柔性提醒，不使用紅色錯誤或警告樣式。
