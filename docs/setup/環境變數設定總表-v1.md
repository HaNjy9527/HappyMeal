## 1. 文件定位

本文件是 Reference 參考文件，目的不是教你一步一步部署，而是提供一個可查表的環境變數總表。

適用對象：

1. 需要確認某個環境變數到底給誰用的開發者
2. 要排查「為什麼本機可跑、上線後失效」的人
3. 需要整理 GitHub Secrets、Vercel、Lightsail 設定的人

本文件包含：

1. 目前程式碼已使用的環境變數
2. 本機開發與正式部署各自要設在哪裡
3. 已過時或已改名的舊變數名稱

本文件不包含：

1. 真實 secret 值
2. 各平台畫面操作截圖
3. LINE Developers Console 的詳細申請流程

## 2. 目前部署架構

HappyMeal 目前採用以下部署方式：

1. 前端 Frontend：Vercel
2. 後端 Backend：AWS Lightsail Container Service
3. 資料庫 Database：AWS Lightsail Database PostgreSQL

### 2.1 目前正式環境 URL

目前正式環境已確認使用以下網址，後續排查登入、CORS、callback 與前後端串接時，應以這組 URL 為準：

1. 前端 Frontend URL：`https://happy-meal-three.vercel.app/`
2. 後端 Backend URL：`https://happymeal-backend.zyaqqxanc0frj.ap-northeast-1.cs.amazonlightsail.com/`
3. LINE Callback URL：`https://happymeal-backend.zyaqqxanc0frj.ap-northeast-1.cs.amazonlightsail.com/auth/line/callback`

補充：

1. `FRONTEND_URL` 應設為前端 URL，不含額外 path。
2. `VITE_API_BASE_URL` 應設為後端 URL。
3. `LINE_CALLBACK_URL` 必須與 LINE Developers Console 中的 Callback URL 完全一致。

這個架構已在 [docs/部署與用量預估-v1.md](docs/部署與用量預估-v1.md) 與 [docs/System-Architecture-v1.md](docs/System-Architecture-v1.md) 中定義。

環境變數也因此分成四個主要層級：

1. 本機 `.env` 或 `.env.local`
2. Vercel Environment Variables
3. GitHub Secrets
4. Lightsail Container runtime environment

重要原則：

1. 前端的 `VITE_*` 變數是 build-time 變數，對 Vercel 來說要設在 Vercel，不是只設 GitHub Secrets。
2. 後端的敏感設定由 GitHub Secrets 注入到 Lightsail runtime。
3. 本機 `.env` 只用於本地開發，不應 commit 真實值。

## 3. 環境變數總表

### 3.1 後端應用程式 Backend Runtime

| 變數名稱                    | 目前狀態 | 用途                                | 本機設定位置 | 正式環境設定位置                  | 備註                                            |
| --------------------------- | -------- | ----------------------------------- | ------------ | --------------------------------- | ----------------------------------------------- |
| `APP_NAME`                  | 已使用   | FastAPI app 名稱                    | `.env`       | 可選，不設則用預設值              | 預設為 `HappyMeal API`                          |
| `APP_ENV`                   | 已使用   | 區分 development / production       | `.env`       | GitHub Secrets → Lightsail        | production 時會影響 session cookie `https_only` |
| `APP_HOST`                  | 已使用   | 後端 host                           | `.env`       | 通常不需特別設                    | 預設 `0.0.0.0`                                  |
| `APP_PORT`                  | 已使用   | 後端 port                           | `.env`       | 通常不需特別設                    | 預設 `8000`                                     |
| `CORS_ALLOW_ORIGINS`        | 已使用   | FastAPI CORS allow origins          | `.env`       | GitHub Secrets → Lightsail        | 建議用逗號分隔多個 origin                       |
| `DATABASE_URL`              | 已使用   | SQLAlchemy / Alembic DB 連線字串    | `.env`       | GitHub Secrets → Lightsail        | 正式環境應指向 Lightsail Database               |
| `ANALYSIS_UPLOAD_DIR`       | 已使用   | 分析暫存上傳目錄                    | `.env`       | 可選                              | 不設則用 `tmp/analysis-uploads`                 |
| `ANALYSIS_MAX_UPLOAD_BYTES` | 已使用   | 上傳大小限制                        | `.env`       | 可選                              | 不設則用 `5000000`                              |
| `LINE_CHANNEL_ID`           | 已使用   | LINE Login Channel ID               | `.env`       | GitHub Secrets → Lightsail        | 敏感資料，不要放前端                            |
| `LINE_CHANNEL_SECRET`       | 已使用   | LINE Login Channel Secret           | `.env`       | GitHub Secrets → Lightsail        | 敏感資料，不要放前端                            |
| `LINE_CALLBACK_URL`         | 已使用   | LINE OAuth callback URL             | `.env`       | GitHub Secrets → Lightsail        | 必須和 LINE Console 完全一致                    |
| `SESSION_SECRET_KEY`        | 已使用   | Session 簽名密鑰                    | `.env`       | GitHub Secrets → Lightsail        | 至少 32 字元                                    |
| `FRONTEND_URL`              | 已使用   | callback 完成後 redirect 的前端網址 | `.env`       | GitHub Secrets → Lightsail        | 應設成 Vercel 網址                              |
| `AI_API_KEY`                | 已使用   | AI 食物辨識服務金鑰                 | `.env`       | GitHub Secrets → Lightsail        | 若目前功能未串正式供應商，可先留空              |
| `NUTRITION_DATA_SOURCE`     | 已使用   | 營養資料來源識別字串                | `.env`       | GitHub Secrets → Lightsail 或留空 | 目前屬於可選設定                                |

### 3.2 前端 Frontend Build-Time

| 變數名稱            | 目前狀態 | 用途              | 本機設定位置           | 正式環境設定位置             | 備註                                                 |
| ------------------- | -------- | ----------------- | ---------------------- | ---------------------------- | ---------------------------------------------------- |
| `VITE_API_BASE_URL` | 已使用   | 前端 API base URL | `.env` 或 `.env.local` | Vercel Environment Variables | 不能只設 GitHub Secrets，因為 Vite 會在 build 時寫死 |

### 3.3 本機 Docker / PostgreSQL

| 變數名稱            | 目前狀態 | 用途                        | 本機設定位置 | 正式環境設定位置                | 備註                           |
| ------------------- | -------- | --------------------------- | ------------ | ------------------------------- | ------------------------------ |
| `POSTGRES_DB`       | 已使用   | 本機 docker compose DB 名稱 | `.env`       | 不用設在 Vercel / Lightsail app | 給本機 PostgreSQL container 用 |
| `POSTGRES_USER`     | 已使用   | 本機 docker compose DB 帳號 | `.env`       | 不用設在 Vercel / Lightsail app | 給本機 PostgreSQL container 用 |
| `POSTGRES_PASSWORD` | 已使用   | 本機 docker compose DB 密碼 | `.env`       | 不用設在 Vercel / Lightsail app | 僅限本機開發                   |
| `POSTGRES_PORT`     | 已保留   | 本機 PostgreSQL 對外 port   | `.env`       | 不用設在正式環境                | 目前 compose 主要用固定映射    |

### 3.4 GitHub Actions / 部署流程

| 變數名稱                | 目前狀態 | 用途                                        | 設定位置       | 備註            |
| ----------------------- | -------- | ------------------------------------------- | -------------- | --------------- |
| `AWS_ACCESS_KEY_ID`     | 已使用   | GitHub Actions 部署到 AWS 的 IAM Access Key | GitHub Secrets | 只給 Actions 用 |
| `AWS_SECRET_ACCESS_KEY` | 已使用   | GitHub Actions 部署到 AWS 的 IAM Secret Key | GitHub Secrets | 只給 Actions 用 |

說明：

1. GitHub Secrets 本身不是前端執行環境。
2. GitHub Secrets 主要作用是讓 Actions 在 deploy 時把後端環境變數注入到 Lightsail。
3. 若前端部署在 Vercel，`VITE_API_BASE_URL` 要設在 Vercel，不是 GitHub Secrets。

## 4. 各平台應該設哪些變數

### 4.1 本機 `.env`

建議放以下變數：

```env
APP_NAME=HappyMeal API
APP_ENV=development
APP_HOST=0.0.0.0
APP_PORT=8000

POSTGRES_DB=happymeal
POSTGRES_USER=happymeal
POSTGRES_PASSWORD=change_me_local
POSTGRES_PORT=5432

CORS_ALLOW_ORIGINS=http://localhost:5173,http://127.0.0.1:5173,http://localhost:4173,http://127.0.0.1:4173
DATABASE_URL=postgresql+psycopg://happymeal:change_me_local@db:5432/happymeal
VITE_API_BASE_URL=http://localhost:8000

ANALYSIS_UPLOAD_DIR=tmp/analysis-uploads
ANALYSIS_MAX_UPLOAD_BYTES=5000000

LINE_CHANNEL_ID=your_line_channel_id
LINE_CHANNEL_SECRET=your_line_channel_secret
LINE_CALLBACK_URL=https://your-backend-url/auth/line/callback
SESSION_SECRET_KEY=replace_with_random_secret
FRONTEND_URL=http://localhost:5173

AI_API_KEY=
NUTRITION_DATA_SOURCE=
```

### 4.2 Vercel

Vercel 至少要設：

```env
VITE_API_BASE_URL=https://happymeal-backend.zyaqqxanc0frj.ap-northeast-1.cs.amazonlightsail.com
```

如果沒有這個值，frontend build 會退回 localhost fallback。

### 4.3 GitHub Secrets

目前建議保留以下 Secrets：

```text
AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY
CORS_ALLOW_ORIGINS
DATABASE_URL
LINE_CHANNEL_ID
LINE_CHANNEL_SECRET
LINE_CALLBACK_URL
SESSION_SECRET_KEY
FRONTEND_URL
AI_API_KEY
NUTRITION_DATA_SOURCE
```

### 4.4 Lightsail Container Service Runtime

Lightsail container 應由 GitHub Actions deployment 注入以下變數：

```text
APP_ENV
CORS_ALLOW_ORIGINS
DATABASE_URL
LINE_CHANNEL_ID
LINE_CHANNEL_SECRET
LINE_CALLBACK_URL
SESSION_SECRET_KEY
FRONTEND_URL
AI_API_KEY
NUTRITION_DATA_SOURCE
```

## 5. 已過時或已改名的舊變數

以下名稱仍可能出現在舊文件或舊設定中，但目前不建議再用：

| 舊名稱              | 新名稱              | 說明                                                 |
| ------------------- | ------------------- | ---------------------------------------------------- |
| `VITE_BACKEND_URL`  | `VITE_API_BASE_URL` | 前端目前應維持使用 `VITE_API_BASE_URL`               |
| `LINE_REDIRECT_URI` | `LINE_CALLBACK_URL` | 後端 Settings 與 LINE Login 文件已改成 callback 命名 |
| `AI_FOOD_API_KEY`   | `AI_API_KEY`        | 目前應維持使用 `AI_API_KEY`                          |

## 6. 目前最容易出錯的點

1. 把 `VITE_API_BASE_URL` 只設在 GitHub Secrets。
   說明：前端部署在 Vercel 時，GitHub Secrets 不會自動進入 Vercel build。

2. GitHub Secrets 有值，但 GitHub Actions deploy workflow 沒有把它注入 Lightsail。
   說明：Secrets 存在不代表後端 container 真的讀得到，還要看 workflow deployment JSON 是否有帶上。

3. `CORS_ALLOW_ORIGINS` 格式錯誤。
   說明：目前程式碼支援逗號分隔字串，較不建議手動塞錯 JSON 格式。

4. LINE Console 的 callback URL 與 `LINE_CALLBACK_URL` 不一致。
   說明：這兩者必須完全一致，包含 path 與斜線。
